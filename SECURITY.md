## Security

NVIDIA works to keep its software products and services secure. This includes
source code in repositories managed by NVIDIA.

Use the private contact channels below to report a security issue. **Do not
report security vulnerabilities through public GitHub issues, discussions, or
pull requests.** If an issue is shared publicly, NVIDIA maintainers may limit
the discussion and ask the reporter to use a private channel.

## Report a possible security issue

To report a possible security issue in an NVIDIA product, use either channel:

- Web: [Report a Security Vulnerability or NVIDIA AI Concern](https://www.nvidia.com/en-us/security/report-vulnerability/)
- Email: [psirt@nvidia.com](mailto:psirt@nvidia.com)

NVIDIA encourages you to encrypt email reports with its
[public PGP key](https://www.nvidia.com/en-us/security/pgp-key/).

Include these details in your report:

- The affected product or driver and its version or branch.
- The type of security issue and its possible impact.
- Steps to reproduce the issue.
- Code that shows or exploits the issue, if you have it.

NVIDIA coordinates with reporters before sharing vulnerability details publicly.
See the [NVIDIA PSIRT policies](https://www.nvidia.com/en-us/security/psirt-policies/)
for the disclosure process.
