# NeMo Guardrails worker plugin

This package runs NeMo Guardrails as a managed NeMo Relay Python worker.
It requires NeMo Relay 0.10 or newer and NeMo Guardrails 0.24.1.

The user guide, migration guide, and runnable examples are maintained in
separate layers of this pull request stack.
